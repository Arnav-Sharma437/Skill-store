# Brand Logos Directory

Place your brand logo image files here (`.svg`, `.png`, `.jpg`, or `.webp`).

### Available Brand Logos:
- `tuqo.svg` (or `tuqo.png`)
- `pumpkin.svg` (or `pumpkin.png`)
- `mitsuki.svg` (or `mitsuki.png`)
- `metso.svg` (or `metso.png`)
- `costec.svg` (or `costec.png`)
- `ultratouch.svg` (or `ultratouch.png`)

These images are automatically loaded in the **Header "Shop by Brands" dropdown** and **Top Brands Carousel** on the storefront.
